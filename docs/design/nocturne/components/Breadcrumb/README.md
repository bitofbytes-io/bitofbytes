# Breadcrumb

One-level trail above a project's hero: "Projects / <Project name>".

- `nav aria-label="Breadcrumb"` in `mono` 14px. The Projects link is `ink-muted`, the slash `ink-subtle` and `aria-hidden`, the current name `ink` with `aria-current="page"`.
- Only used on project detail pages. It replaces any previous/next navigation: detail pages have none.
