# HobbyCard

One of the three "Off the clock" cards on Home: Programming, Piano, Videogames.

- An `nc-card nc-hobby`: a 40px stroke icon in `accent` (code brackets, piano, gamepad), a `card-title` heading, two sentences of `ink-muted` copy, and a "now" line in `mono` 13px under a `line` rule, pinned to the bottom so the three cards align.
- Each card links (with `nc-prose-link`) to the project the hobby inspired where one exists: Piano to Noted, Videogames to Anthology.
- The "now" line is personal and current. Until Daniel supplies it, keep the bracketed placeholder; never make one up.
- Three across on desktop (`nc-hobbies`, 24px gap) inside the `nc-band`; stacked on phone. Exactly three cards: no fourth hobby without Daniel adding one.
